# Pudget 記帳布 🍮

> 隨手記一筆，自動寫進 Google Sheet 記帳本的個人記帳 PWA。
> 名稱取自 **pud**ding + bud**get**，中文「布」為布丁諧音。

Pudget 是為了「花錢的當下就能隨手記帳」而做的手機網頁工具，取代事後回家補登。
記帳資料寫進你自己既有的 Google Sheet 記帳本，月報表、分帳結算仍沿用你原本的公式，
Pudget 只負責把每一筆花費快速、正確地加進去。

## 功能

**快速記一筆**
金額、日期、付款人、分類、項目、備註一頁搞定，常用項目可下拉，代墊款自動標成紅字。

**與 Google Sheet 整合**
依日期寫進當年度記帳本的月份分頁，共用錢包自動雙寫，月報表與分帳公式完全不受影響。

**離線也能記**
沒訊號先存在手機，連上網路自動補傳且不重複，右上角燈號顯示同步狀態。

**紀錄**
隨時檢視這支手機的待同步與已同步清單，完整帳目仍在 Google Sheet 查閱與編輯。

**設定**
管理常用項目、切換淺色 / 深色 / 跟隨系統主題、設定後端連線（僅存於各自手機）。

**當 App 用**
RWD 網頁可用 Safari 加入主畫面，布丁黃色系介面，支援深淺色。

## 技術架構

| 層 | 內容 |
|---|---|
| 前端 | React + TypeScript + Vite，PWA（vite-plugin-pwa） |
| 圖示 | [@tabler/icons-react](https://tabler.io/icons) |
| 樣式 | CSS 變數（design tokens），系統圓體字型（零下載、離線可用） |
| 後端 | Google Apps Script Web App（以試算表擁有者身分執行，寫入 Sheet） |
| 部署 | GitHub Pages（GitHub Actions 自動建置部署） |

**設計原則**
- 前端 write-only：只負責寫入，不讀取整本帳；查閱與編輯在 Google Sheet 進行
- 存取控管靠使用者自訂的通關碼（token），設定值只存在裝置本機，不進 repo
- 真實金流資料一律不進版控
